# 정관 맛집 지도 (개인용)

부산 기장군 정관읍의 음식점만 지도에 표시하고, 식당을 누르면 카카오맵·네이버 지도·구글 지도로 바로 가는 링크와
내 별점/메모, AI 한줄평을 보여 주는 웹페이지입니다.

## 하는 일
- 카카오 지도에서 정관읍 음식점을 모아 지도와 목록에 표시 (카페는 제외, 음식점 분류만)
- 음식 종류 칩(한식, 중식 등) 필터, 이름 검색, 정렬(가까운 순 / 내 별점 순 / 이름 순)
- 식당 카드: 주소, 전화, 세 지도 앱 링크, AI 한줄평, 내 별점과 메모
- 내 별점과 메모는 **이 기기의 브라우저에만** 저장됩니다. (다른 폰에서는 보이지 않습니다)

## 리뷰에 대하여
다른 사이트의 리뷰를 자동으로 긁어 오지 않습니다. 대신 각 지도 앱으로 연결하는 링크를 제공합니다.
AI 한줄평은 `oneliners.json`에 적어 둔 문장을 보여 줍니다. 직접 읽고 모은 후기를 정리해서 넣으세요.

## 설치 방법
1. **카카오 키 받기**: developers.kakao.com 에서 로그인 → 내 애플리케이션 → 앱 만들기 → 앱 키에서 **JavaScript 키** 복사
   - 플랫폼(Web)에 사이트 주소를 등록: `https://내아이디.github.io`
   - 카카오맵 사용 설정 항목이 있으면 켜 주세요. (메뉴 이름은 바뀔 수 있어요)
2. **GitHub에 올리기**: 새 저장소(공개)를 만들고 이 폴더의 파일 3개(index.html, oneliners.json, README.md)를 업로드
3. **키 넣기**: GitHub에서 index.html을 열고 연필(편집) 버튼 → 위쪽 `KAKAO_JS_KEY: ""` 의 따옴표 안에 키를 붙여 넣고 저장
4. **웹페이지로 열기**: 저장소 Settings → Pages → Branch를 main으로 선택 → 잠시 뒤 `https://내아이디.github.io/저장소이름/` 에서 열림
5. 폰에서 그 주소를 열고 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

## 한줄평 넣는 방법
`oneliners.json`에 `"식당 이름": "한 줄 평"` 형태로 추가합니다. 식당 이름은 지도에 보이는 이름과 똑같이 적어야 합니다.

## 설정 값 (index.html 위쪽 CONFIG)
- `CENTER`: 지도 중심 좌표. 위치가 어긋나면 숫자를 조금 고치세요.
- `AREA_WORD`: 주소에 이 글자가 있는 식당만 보여 줍니다. (기본 "정관")
- `CACHE_HOURS`: 같은 결과를 재사용하는 시간. 식당을 모으는 요청 수를 줄여 줍니다.

## 확인한 것과 한계
- 가짜 카카오 지도 응답으로 화면 동작(필터, 검색, 정렬, 카드, 별점과 메모 저장, 새로고침 후 유지)을 확인했습니다.
- **실제 카카오 키로는 아직 테스트하지 못했습니다.** 키를 넣은 뒤 지도와 식당이 뜨는지 확인해 주세요.
- 카카오 지도에 등록된 식당만 나오며, 최신 정보와 다를 수 있습니다.
- 카카오 API는 사용 조건과 한도가 있으니 카카오 개발자 문서를 확인하세요.
